Repeatable infrastructure

Use modular Terraform and Ansible AAP to make provisioning and configuration consistent across environments.

In a banking environment, I developed modular Terraform infrastructure and Ansible Automation Platform playbooks for provisioning and configuration.

The focus was consistency: reduce manual setup, keep environment differences explicit, and make infrastructure changes easier to review and explain.

  • Organize infrastructure as reusable Terraform modules.
  • Automate server provisioning and configuration with Ansible AAP.
  • Partner with development teams on containerized deployments.

The practical value is a system another engineer can understand, reproduce and maintain.
