## 3. กลุ่ม Facebook (ฟรีแลนซ์ไทย / รับงาน IT / DevOps Thailand)

> โพสต์ตอนเช้าวันธรรมดา ~9 โมง หรือ ~2 ทุ่ม คนอ่านเยอะสุด
> ถ้ากลุ่มไหนห้ามลิงก์ ให้ใส่ลิงก์ในคอมเมนต์แรกแทน

```
[แชร์ความรู้] บิล AWS มันไปกองอยู่ตรงไหน — เผื่อใครกำลังงงกับบิลตัวเอง

ทำงานสาย cloud มาพักใหญ่ เจอคำถามนี้บ่อยมากจนอยากเขียนสรุปไว้
"ทำไมบิล AWS มันขึ้นทุกเดือน ทั้งที่ไม่ได้เพิ่มอะไร"

บิลของเว็บหนึ่งเว็บมักมีของ 5 ก้อน ถ้าเข้าใจ 5 ก้อนนี้ อ่านบิลตัวเองออกไป 90% แล้ว
ตัวที่ดันราคาแล้วคนมองข้ามบ่อยสุดคือ 3 ตัวนี้

· NAT Gateway — คิดทั้งรายชั่วโมง และคิดตามข้อมูลที่วิ่งผ่าน (โดนสองเด้ง)
· Data transfer ขาออก — ยิ่งคนเข้าเว็บเยอะ ยิ่งจ่ายเยอะ
· EBS snapshot + ดิสก์ของเครื่องที่ปิดไปแล้วแต่ไม่ได้ลบ — ปิดเครื่องแล้วแต่ดิสก์ยังเก็บเงินอยู่

ข้อสุดท้ายนี่แหละที่เจอบ่อยสุด หลายที่มีดิสก์ค้างจากเครื่องที่เลิกใช้ไปเป็นปี

เขียนแจกแจงละเอียดพร้อมช่วงงบ 3 ระดับสำหรับเว็บ SME ไว้ที่นี่ครับ
https://korvuz.site/blog/aws-cost-sme-thailand/

ปล. ตัวเลขในบทความเป็นช่วงประมาณการนะครับ ไม่ใช่ใบเสนอราคา
ก่อนตัดสินใจจริงให้กด AWS Pricing Calculator อีกที
```

## 4. Pantip (ห้องเทคโนโลยี / ห้องสินธร)

> **วิธีที่ได้ผลกว่าตั้งกระทู้ใหม่: ไปตอบกระทู้ที่มีคนถามอยู่แล้ว**
> ค้นใน Pantip: `ค่าทำเว็บ ราคา` · `จ้างทำเว็บ บริษัท` · `ค่า AWS แพง` · `จ้างฟรีแลนซ์ IT`
> ตอบให้จบในตัวก่อน แล้วค่อยแปะลิงก์บรรทัดสุดท้าย

**ร่างคำตอบ (กระทู้แนว "จ้างทำเว็บบริษัท ราคาเท่าไหร่ถึงเรียกว่าไม่โดนโกง"):**
```
ขอตอบในฐานะคนทำสายนี้นะครับ ราคาที่ต่างกันหลายเท่ามันมีเหตุผลจริง ๆ ไม่ได้ฟันอย่างเดียว
สิ่งที่ทำให้ต่างกันมากที่สุดคือ 3 อย่าง

1. เว็บ static หรือ WordPress — static ถูกกว่าและเร็วกว่ามาก แต่แก้เนื้อหาเองไม่ได้
   ถ้าไม่ได้แก้เนื้อหาบ่อย static คุ้มกว่าเยอะ หลายเจ้าเสนอ WordPress ทั้งที่ไม่จำเป็น

2. ดีไซน์ทำใหม่ หรือใช้ธีมสำเร็จ — อันนี้ต่างกันได้เป็นเท่าตัว
   ถามให้ชัดว่า "ออกแบบใหม่" คือวาดใหม่จริง หรือแค่เปลี่ยนสีธีมที่ซื้อมา

3. ค่าที่ต้องจ่ายทุกปีแต่ไม่อยู่ในใบเสนอราคา — โดเมน โฮสติ้ง SSL ค่าดูแล
   ตรงนี้ที่คนโดนบ่อย ปีแรกถูก ปีสองงง

เวลาเทียบใบเสนอราคาสองเจ้า ให้ถามคำถามเดียวกันทั้งคู่ว่า
"หลังส่งมอบ ผมแก้เนื้อหาเองได้ไหม และปีหน้าต้องจ่ายอะไรบ้าง"
คำตอบมักแยกได้เลยว่าเจ้าไหนตรงไปตรงมา

ผมเขียนแจกแจงไว้ยาว ๆ เผื่อมีประโยชน์ครับ
https://korvuz.site/blog/website-price-thailand-2026/
```
