## 📊 วิเคราะห์ SEO จาก nginx log (14 วันย้อนหลัง)

**สรุป: technical SEO เสร็จแล้วและไม่ใช่ตัวที่ขวาง — ตัวที่ขวางคือไม่มี backlink เลย**

1. **Googlebot แทบไม่ไต่หน้าใน** — `/work/` **0 ครั้ง** · `/blog/` **1 ครั้ง** · `/sitemap.xml` 2 ครั้ง
   (หน้า `/` แยกไม่ได้ว่าของ host ไหน เพราะ `/var/log/nginx/access.log` รวมทุก vhost และไม่มีช่อง `$host`)
2. **ยังไม่มีคนหาเจอจากการค้นหา** — referrer จาก google.com 184 ครั้ง แต่**เกือบทั้งหมดเป็นบอตปลอม referrer**
   ยิงหา `/.env` `/wp-login.php` `/.git/config` (23 ส.ค. วันเดียว 171 ครั้ง = โดนสแกนเป็นระลอก)
   ที่เป็นคนจริงมีไม่กี่ครั้ง และค้นคำว่า `korvuz.site` / `doc.korvuz.site` ตรง ๆ = คนที่รู้ชื่ออยู่แล้ว
3. **ไม่มี backlink จริงสักอัน** — referrer ที่เหลือมีแต่ IP สแกนเนอร์ กับ `t.co` 4 ครั้ง
4. 🟢 **AI crawler ไต่หนักกว่า Google** — GPTBot 417 · ClaudeBot 272 · bingbot 246 · **Googlebot 144**
   การเป็นแหล่งที่ AI ดึงไปตอบ = ช่องทางลูกค้าจริง และมันชอบสิ่งที่เว็บมีอยู่แล้ว (ราคาชัด FAQ เป็นข้อ ๆ)

**คำสั่งที่ใช้ดึง log** (ต้อง sudo เพราะ log เป็นของ `www-data:adm`):
```bash
cd /var/log/nginx
sudo bash -c '(zcat -f access.log*.gz; cat access.log access.log.1)' | grep -i Googlebot | awk '{print $9, $7}' | sort | uniq -c | sort -rn
```

**ความคาดหวังตามจริง: 3–6 เดือนกว่า impressions จะขยับ ไม่ใช่ 2 สัปดาห์**
