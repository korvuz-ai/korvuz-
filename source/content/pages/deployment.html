ทั้ง 5 ตัวรันอยู่บนเครื่องเดียว ใช้ Docker แยก container, Nginx เป็น reverse proxy, SSL ต่ออายุอัตโนมัติด้วย Certbot และมี Grafana + Prometheus เก็บ metrics ของเครื่องกับ container (CPU, RAM, ดิสก์) — นี่คือ stack เดียวกับที่ใช้ตอนรับงานลูกค้า

และขอพูดตรง ๆ ข้อหนึ่ง: ชุด monitoring ข้างบนเก็บ metrics ของเครื่อง ไม่ได้ เช็กว่าแต่ละเว็บยังเปิดอยู่ไหม ซึ่งเป็นคนละเรื่องกัน — งานลูกค้าจะต้องมี uptime check แยกต่างหาก พร้อมแจ้งเตือนเมื่อเว็บล่ม เพราะกราฟ CPU สวย ๆ ไม่ได้แปลว่าเว็บยังตอบ 200
