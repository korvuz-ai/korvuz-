ผลงานที่ใช้งานจริง — SaaS 5 ตัวที่สร้างและดูแลเองทั้งระบบ

ทุกตัวในหน้านี้เปิดให้กดเข้าไปดูได้จริง ไม่ใช่ภาพ mockup — เขียนโค้ดเอง ทำ CI/CD เอง ดูแล server, DNS, SSL และ monitoring เอง ตั้งแต่วันแรกจนวันนี้ สิ่งที่อยากให้ดูไม่ใช่แค่หน้าเว็บสวย แต่คือระบบที่ยังอยู่และยังทำงานอยู่หลังผ่านไปเป็นปี

1. InvoiceAI — ออกใบแจ้งหนี้ภาษาไทยด้วย AI

invoice.korvuz.site — SaaS สำหรับฟรีแลนซ์และ SME ไทย พิมพ์รายละเอียดงานเป็นภาษาพูด แล้วระบบจัดเป็นใบแจ้งหนี้ ใบเสนอราคา หรือใบเสร็จให้ พร้อมคำนวณ VAT 7% และหัก ณ ที่จ่าย 3% ให้อัตโนมัติ ดาวน์โหลดเป็น PDF ส่งลูกค้าได้ทันที

โจทย์ที่ยากจริงของงานนี้ไม่ใช่การเรียก AI แต่คือ PDF ภาษาไทย — ฟอนต์ไทยบน PDF renderer ส่วนใหญ่สระลอยและวรรณยุกต์เพี้ยน แก้ด้วยการฝังฟอนต์ Sarabun ลงไปในตัวแอปเอง ไม่พึ่ง CDN ภายนอก และเรื่องภาษี ที่ต้องคิดจากฐานเดียวกันแต่ตัวหนึ่งบวกเพิ่ม อีกตัวหักออก

Next.js 14 · TypeScript · Gemini API · Prisma/SQLite · Stripe · Docker + Nginx บน EC2

2. LineCRM — CRM ที่อยู่บน LINE OA

crm.korvuz.site — จัดการลูกค้าจาก LINE Official Account, ทำ sales pipeline และใช้ AI ช่วยสรุปบทสนทนา รวมอยู่ที่เดียว

SME ไทยส่วนใหญ่ปิดการขายกันบน LINE แต่ CRM ที่ขายกันทั่วไปออกแบบมาจากฝั่งอีเมล ทำให้ข้อมูลลูกค้ากระจัดกระจายอยู่ในแชทที่ค้นย้อนหลังไม่ได้ ตัวนี้เลยเริ่มจากฝั่ง LINE ก่อน แล้วค่อยต่อ pipeline เข้าไป ไม่ใช่บังคับให้ลูกค้าย้ายมาใช้เครื่องมือใหม่ทั้งหมด

LINE Messaging API · PostgreSQL · worker queue (Redis) · Docker Compose

3. FiatLine — ผู้ช่วยจัดการเงินบน LINE

line.korvuz.site — ถ่ายรูปสลิปส่งเข้า LINE แล้วระบบอ่านยอดเงินบันทึกรายจ่ายให้อัตโนมัติ ตั้งงบประมาณและเป้าออมเงินได้ในแชทเดิมที่ใช้อยู่ทุกวัน

จุดที่ทำให้แอปบันทึกรายจ่ายส่วนใหญ่ล้มเหลวคือ คนขี้เกียจเปิดแอป ตัวนี้เลยไม่มีแอปให้เปิด — ใช้ที่เดียวกับที่สลิปถูกส่งมาอยู่แล้ว ลดขั้นตอนจาก "เปิดแอป → พิมพ์ยอด → เลือกหมวด" เหลือแค่ส่งรูป

LINE Messaging API · OCR · PostgreSQL · background worker

4. English Reader — ฝึกอ่านอังกฤษจากเรื่องสั้น

en.korvuz.site — อ่านเรื่องสั้นระดับคำศัพท์ 3,000 คำ มีเสียงอ่าน กดที่คำไหนก็ขึ้นคำแปลไทย และมีเกมจับคู่คำศัพท์ทบทวนท้ายบท

ทำขึ้นเพราะสื่อฝึกภาษาอังกฤษส่วนใหญ่บังคับให้ท่องศัพท์เป็นลิสต์ ทั้งที่คนจำคำได้ดีที่สุดตอนเจอมันในบริบท ตัวนี้เลยให้อ่านเรื่องก่อน แล้วค่อยเก็บคำที่ไม่รู้ระหว่างทาง

5. DevOps KB — คลังความรู้สาย DevOps

doc.korvuz.site — knowledge base รวม visualization, cheatsheet และ interactive lab สำหรับ DevOps engineer เขียนด้วย vanilla JS ล้วน ไม่มี dependency ให้ต้องอัปเดตตาม รันได้ทุกที่ที่มี browser

เป็นที่ที่เก็บสิ่งที่เจอจากงานจริง — ทั้ง Terraform pattern ที่ใช้ซ้ำได้ และเคสที่เคยพังแล้วได้บทเรียน

แล้วสิ่งนี้เกี่ยวอะไรกับงานที่คุณจะจ้าง

ทั้ง 5 ตัวรันอยู่บนเครื่องเดียว ใช้ Docker แยก container, Nginx เป็น reverse proxy, SSL ต่ออายุอัตโนมัติด้วย Certbot และมี Grafana + Prometheus เก็บ metrics ของเครื่องกับ container (CPU, RAM, ดิสก์) — นี่คือ stack เดียวกับที่ใช้ตอนรับงานลูกค้า

และขอพูดตรง ๆ ข้อหนึ่ง: ชุด monitoring ข้างบนเก็บ metrics ของเครื่อง ไม่ได้ เช็กว่าแต่ละเว็บยังเปิดอยู่ไหม ซึ่งเป็นคนละเรื่องกัน — งานลูกค้าจะต้องมี uptime check แยกต่างหาก พร้อมแจ้งเตือนเมื่อเว็บล่ม เพราะกราฟ CPU สวย ๆ ไม่ได้แปลว่าเว็บยังตอบ 200
